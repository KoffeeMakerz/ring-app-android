# Store notes

Two living notes on what Kinnora must meet to pass review, what's done and what's still open:

- [app-store.md](app-store.md): Apple App Store (iPhone app and Apple Watch app).
- [google-play.md](google-play.md): Google Play (phone app and Wear OS app).

The same files are kept in both repos (ring-app-ios and ring-app-android) and in the project's
`store-compliance.md`.

**Rule:** every change that touches permissions, data leaving the phone, AI, payments, health
features, background behaviour, store wording or videos updates these notes in the same commit.
Add a line to the change log at the bottom of the note you changed.

Status words: **Blocker** = will be rejected; **To do** = needed before submitting;
**Check** = verify in the submission; **OK** = handled.
